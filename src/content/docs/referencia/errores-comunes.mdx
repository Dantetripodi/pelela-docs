## Técnica de depuración

Reducí el caso a una propiedad, un binding y un evento. Si ese circuito funciona, agregá el
resto de la pantalla de a una pieza. Mirá primero la consola y después la estructura generada.

La documentación oficial del repositorio también separa arquitectura, binding/reactividad,
componentes/routing, CLI y extensión de VS Code. Esas referencias sirven para profundizar
cuando el concepto ya está claro.

En PelelaJS 1.2.2, el autorregistro revisa que cada `view-model` sea una clase exportada por el
archivo `.ts` correspondiente. También muestra la pantalla de error ante configuraciones inválidas
de routing o layouts y ante errores síncronos o asíncronos en handlers `click` y `enter`. Leé el
mensaje completo: incluye la causa y, para errores del ViewModel, el archivo que debés corregir.
