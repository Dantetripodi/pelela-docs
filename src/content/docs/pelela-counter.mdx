## Estado, evento y vista en acción

Esta página está escrita en MDX, pero el contador se monta con PelelaJS usando el plugin oficial.
Probá los botones y después relacioná cada parte con el código.

<PelelaCounter />

## Codigo Pelela

```html title="app.pelela"
<pelela view-model="App" class="pelela-counter">
  <button click="decrement">-</button>
  <p bind-content="counter"></p>
  <button click="increment">+</button>
</pelela>
```

```ts title="app.ts"
export class App {
  counter = 0

  increment() { this.counter++ }
  decrement() { this.counter-- }
}
```

La demostración es deliberadamente chica: `counter` es el estado, los botones son eventos y el
`p` es la vista conectada mediante `bind-content`.
