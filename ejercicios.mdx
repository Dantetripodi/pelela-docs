## Criterio de entrega

Para cada ejercicio explicá:

- cuál es el estado mínimo;
- qué eventos lo modifican;
- qué parte de la vista depende de cada propiedad;
- qué pasa en el caso vacío o inválido.

El objetivo no es escribir más código, sino poder justificar la relación entre modelo, vista y
eventos.

<InteractiveExercise
  title="01 · Completar un contador"
  description="Completá los dos métodos del ViewModel. Cuando la solución sea correcta, se habilita la vista previa para probar los eventos."
  initialCode={`export class App {
  counter = 0

  increment() {
    // completar
  }

  decrement() {
    // completar
  }
}`}
  solutionCode={`export class App {
  counter = 0

  increment() {
    this.counter++
  }

  decrement() {
    this.counter--
  }
}`}
