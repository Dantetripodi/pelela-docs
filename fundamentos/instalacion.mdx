## Instalación

La forma recomendada para trabajar los ejemplos es un proyecto Vite con el paquete de PelelaJS
y su plugin oficial.

Necesitás Node.js 22 o superior y `pnpm`. También podés instalar la CLI global para generar un
proyecto inicial:

```bash
pnpm add -g pelelajs
pelela init MiApp
```

La CLI crea una estructura mínima basada en un template. Si preferís entender cada archivo desde
el comienzo, podés armar la estructura manualmente con los pasos de esta página.

```bash
pnpm add pelelajs
pnpm add -D vite-plugin-pelelajs typescript
```

## Estructura recomendada

Separá la estructura visual, el estado y los estilos. Así cada archivo tiene una responsabilidad
fácil de explicar y la aplicación puede crecer sin convertirse en un único archivo enorme.

```text
mi-app/
├── index.html             # punto de montaje: <div id="app">
├── vite.config.ts         # plugin de PelelaJS
├── package.json            # dependencias y scripts
└── src/
    ├── app.pelela          # estructura HTML y bindings
    ├── app.ts              # ViewModel, estado y eventos
    ├── styles.css          # apariencia de la pantalla
    └── components/         # piezas reutilizables cuando crezca la app
```

El recorrido de una interacción queda así:

```text
usuario → evento en app.pelela → método en app.ts → cambio de estado → binding actualizado
```

Para los primeros ejercicios alcanza con `app.pelela`, `app.ts` y `styles.css`. Agregá
`components/` cuando una parte tenga nombre propio, se repita o tenga una responsabilidad aislable.

En `vite.config.ts` se agrega el plugin:

```ts
import { defineConfig } from 'vite'
import { pelelajsPlugin } from 'vite-plugin-pelelajs'

export default defineConfig({
  plugins: [pelelajsPlugin()],
})
```

El plugin procesa los templates `.pelela` y registra los ViewModels que encuentra en `src`.
Para empezar, mantené cada demo pequeña y con nombres fáciles de ubicar.

## Primer montaje

```ts
import { mountTemplate } from 'pelelajs'
import template from './app.pelela'
import 'virtual:pelela-auto-register'

mountTemplate(document.querySelector('#app')!, template)
```
