## ¿Qué es PelelaJS?

PelelaJS es un **framework de interfaz de usuario creado con fines didácticos**. Está orientado a
quienes están dando sus primeros pasos en el desarrollo frontend y quieren comprender cómo se
construye una aplicación web a partir de **estado, vistas y eventos**.

Su propósito es presentar los conceptos fundamentales de un framework de UI mediante una API
pequeña y directa. Con PelelaJS se pueden desarrollar interfaces reactivas usando `ViewModels`,
bindings, componentes, renderizado condicional, listas y routing, sin ocultar la relación entre
los datos y la vista.

## Propósito y alcance

> **PelelaJS no es un framework comercial.** Es un proyecto educativo pensado para aprender los
> principios que comparten los frameworks modernos y construir un modelo mental que luego pueda
> trasladarse a otras tecnologías.

El foco está puesto en entender:

- **Estado:** cómo representar la información de una pantalla.
- **Eventos:** cómo expresar las acciones que modifican ese estado.
- **Bindings:** cómo mantener sincronizados el modelo y la vista.
- **Componentes:** cómo dividir una interfaz en partes con responsabilidades claras.
- **Routing:** cómo organizar la navegación entre pantallas.

Para comenzar, consultá la guía de [instalación](./fundamentos/instalacion/) y luego el
[modelo mental](./fundamentos/modelo-mental/) de PelelaJS.
