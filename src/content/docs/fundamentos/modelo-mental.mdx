Los ejemplos de esta sección parten de una pantalla creada con `pelela new App`. Pelela CLI genera
juntos `app.ts`, `app.pelela` y `app.css`; acá nos concentramos en la responsabilidad de los dos
primeros archivos.

## El modelo mental

Una interfaz Pelela puede pensarse como un ciclo:

```text
estado → render de la vista → evento del usuario → cambio de estado → render
```

El ViewModel concentra los datos y las operaciones. El template describe dónde mostrar esos
datos y qué acciones invocar.

```ts
export class App {
  counter = 0

  increment() {
    this.counter++
  }
}
```

```html
<pelela view-model="App">
  <p bind-content="counter"></p>
  <button click="increment">Sumar</button>
</pelela>
```

La vista no necesita buscar manualmente el elemento ni escribir `textContent`. Declara la
relación y Pelela mantiene esa relación actualizada.
