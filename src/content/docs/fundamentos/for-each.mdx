## For Each

`for-each` relaciona una colección del ViewModel con una plantilla repetible. Si cambia la
colección, Pelela actualiza los elementos correspondientes de la vista.

```html
<ul>
  <li for-each="item of items">
    <span bind-content="item.name"></span>
  </li>
</ul>
```

```ts
export class App {
  items = [
    { name: 'Leer bindings' },
    { name: 'Resolver ejercicios' },
  ]
}
```

### Contexto de cada elemento

Dentro del bloque, `item` representa el elemento actual. El contexto de la iteración también
puede acceder al ViewModel padre, por lo que una acción puede invocar métodos de la aplicación.

```html
<button for-each="item of items" click="removeItem(item)">
  <span bind-content="item.name"></span>
</button>
```

La sintaxis exacta de una acción depende de la versión del framework y de cómo esté armado el
ViewModel; conviene mantener la lógica de modificación en métodos de la clase.

### Caso vacío

Una lista vacía no es un error: es un estado que la interfaz debe explicar.

```html
<p if="items.length === 0">Todavía no hay elementos.</p>
<ul if="items.length > 0">
  <li for-each="item of items">
    <span bind-content="item.name"></span>
  </li>
</ul>
```
